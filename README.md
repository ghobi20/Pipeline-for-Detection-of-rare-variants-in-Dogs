# Pipeline for detecting rare variants associated with congenital diseases in Dogs. 🐕
#### Author: Sofia Gamiño Estrada
#### Affiliation: Laboratory of Mendelian Genomics and Precision Health, LIIGH UNAM.

This is a repository for the bioinformatics pipeline that will be used for the detection of rare variants associated with Mendelian diseases in dogs. 
The aim is to deliver a high-quality list of candidate variants for a specific condition of our furry proband.

Additionally, it contains all the scripts that I used for the creation of a custom annotation database using ANNOVAR, as it is a precise tool used in our laboratory. I used many different public resources to gather variant frequency data in dogs, as there have been many efforts to catalogue existing variation in dogs. This is very useful in the filtration steps.
